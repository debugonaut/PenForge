the previously described comparison. Preparation and code verification are authorized;
real model execution remains owner-only. No training, deployment or promotion is included.

The existing full-alphabet registry remains strict. A separately versioned registry
supports a reviewed subset of A–Z/a–z per writer, with every other character explicitly
excluded as absent, ambiguous or unusable. Included and excluded inventories are disjoint,
unique and exhaustive. Missing letters never become recognition errors. Labels are
reviewer judgments from the image, not model predictions or assumed prompt compliance.

Keeping only complete pages would discard useful writers; pretending all pages contain
52 letters would introduce false labels. The selected approach preserves all four
writers with truthful coverage. The four-writer result remains a small exploratory pilot.

and evaluates the same crops once. It writes private predictions and paired fixes,
regressions, case-sensitive accuracy, case-folded diagnostics and per-writer results.
