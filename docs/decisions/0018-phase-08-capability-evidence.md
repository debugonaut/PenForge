# 0018 — Capability evidence is specific and independent

Status: accepted for explicitly authorized local Phase 08. Date: 2026-10-20.

The capability key is task + script + writing style + input class. Labels describe
that key, never an entire model or product. `production_validated` requires reviewed,
matching, held-out evidence and explicit independent release approval.
`experimental_opt_in` requires a deliberate per-operation opt-in and disclosed limits.
`research_only` is unavailable in the normal creation path. `disabled` has no execution
path. Loading a model, synthetic fixtures or improved OCR cannot qualify handwriting.

Recognition, alignment/segmentation, outline fidelity, held-out writer fidelity,
script shaping, blinded human preference, correction burden and resources each need
their own versioned evidence. Unknown dimensions stay null. Required dimensions cannot
be waived by speed, capacity, cost, prettier output or plausible prompted words.

Phase 08 extends existing style_profiles/model_versions, review/snapshot/export and
privacy services. A second style store or a training runtime would duplicate ownership
and erasure rules; neither is introduced. Deterministic geometric descriptions are
measured engineering outputs, not learned style or recognition claims. Authentic
alternates use distinct samples and explicit approval. Algorithm/model changes offer
new immutable versions and siblings; approved historical revisions/exports never change.

The user's detailed Phase 08 request supplies the design, sequence and authorization.
Work packages run sequentially, with no subtask agents. External data, licenses,
training, paid compute, Devanagari, providers, deployment and Phase 09 remain excluded.
