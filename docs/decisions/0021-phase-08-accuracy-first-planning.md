# 0021 — Qualification precedes capacity

Status: accepted for local Phase 08. Date: 2026-10-20.

The planner matches task/script/style/input exactly against approved component versions.
Production qualification needs matching independent real-writer evidence; regressions
block promotion. Experimental execution needs explicit opt-in. Research-only/disabled
components cannot run. No qualified component yields unsupported/needs-intervention.

Select by independently reviewed quality policy before checking worker, memory, quotas
or degradation. Insufficient capacity queues that qualified version; it cannot pick a
weaker component to meet speed/cost targets. Estimates stay null unless a pinned measured
profile matches full capability, component hash, worker and hardware identities.

Current analyze_samples requests record the existing T0 structured geometry route.
Unstructured input requests isolated recapture; no recognizer/segmenter is substituted.
Existing Phase 06 reservation/admission/fencing remains authoritative. New hypothetical
component plans are infrastructure, not an activated model or production-quality claim.
