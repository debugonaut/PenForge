# 0025 — Approved forms, explicit attachment evidence and conservative fallback

Status: accepted for Phase 09 engineering only. Date: 2026-10-20.

Canonical outline indic evidence is optional and versioned, hash-bound to geometry.
It classifies base/mark/half/reph/rakar/conjunct/contextual forms and carries explicit
font-unit anchors and constrained substitution records. It is part of immutable
candidate/revision/snapshot/export identity. Extraction does not infer anchors or
missing forms. The owner's existing edit then separate approval transition can create
an engineering record. Models/workers cannot approve it. Reference-font controls and
authored synthetic forms have explicit fixture provenance and separate licenses.

Only approved same-project snapshot rows enter compilation. Derive feature source from
these rows, not arbitrary feature text; validate input glyph existence and constrained
semantic contexts, GDEF base/ligature/mark classes and attachment coordinates. Hash the
feature evidence into the explicit Devanagari build profile. Emit no unsupported lookups.

A cluster is tested against actual bytes. Complete scalar inventory does not establish
shaping. Missing dedicated conjuncts may use an explicitly available half form or
visible-virama fallback; record fallback-only status. Missing marks, .notdef, malformed
controls or absent positioning evidence must not be claimed as covered. Unknown text
remains unverified until tested. HarfBuzz performs reordering; no visual swaps in GSUB.
Feature-off output is a diagnostic, not a claim that obligatory Indic features may be
safely disabled by users.

Production/M3 needs licensed corpus-derived 200–500 words, actual writer-disjoint
handwriting evaluation and independent human-reviewed shaping. The eleven starter
sequences are engineering regression controls. No recognizer, corpus-frequency list,
quality threshold, linguistic approval or writer-fidelity claim is invented. Existing
research admission/registry/planner remain independently authoritative.

Privacy: new anchors/forms/sequence evidence live only in existing scoped outline,
result, job, snapshot and report assets/rows. The Phase 07 inventory and deletion saga
cover them; no detached private cache is created. Stale work uses the same live/deferred
publication fences. A project required-set pin is additive and survives old-release
migration; new binaries need the additive schema. Historical fonts are never rewritten.
